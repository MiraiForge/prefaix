# Prefaix 0.1.0

Draft release notes; no package has been published by this implementation.

Prefaix brings a pi coding-agent conversation to zsh, fish, and bash. Type a
colon prompt, read streamed text and tool activity, and continue in your shell.

- zsh 5.8+, fish 3.6+, and bash 4.4+ integrations preserve history and refresh
  prompts. macOS bash 3.2 has a `pfx` fallback.
- Esc/Ctrl+C abort, typed-ahead text returns for review, and daemon crashes
  release the terminal so a later prompt can reconnect.
- MVP conversation/model/thinking commands, status, clipboard, help, and pi
  slash commands; fzf and built-in pickers.
- `prefaix doctor` diagnoses without model requests or environment values.
  `prefaix setup` previews, backs up, and manages the rc integration;
  `prefaix uninstall` reverses its block.
- Generated configuration documentation and automated shell/version, coverage,
  and performance gates.

M4 features (suggest/commit, detach/attach, TUI handoff, and completions)
remain outside this release. Read the [README](../../README.md) for installation
and migration from Forge.

## Measurements and release evidence

Local macOS validation passes the complete E2E matrix on bash 4.4/fish 3.6.4
with Node 22.19 and bash 5.2/fish 4.0.2 with Node 24.21; both include zsh 5.9
and the bash 3.2 fallback. Coverage exceeds 95% in all four metrics.

On the M4 Max with Node 26.7, client hello measured 31.07ms p50 / 32.59ms p95,
first token 54.31ms p50, and ordinary post-use daemon RSS 59.50MiB. The burst
test exceeded 25,000 deltas/second but measured 59.89MiB idle afterward. This
and the ordinary post-use result both fail the <60 MB (57.22MiB) memory gate
and block release. Node 22/24 results and the exact
artifact digest are in [VALIDATION.md](../VALIDATION.md).

The [S8 comparison](../spikes/S8-client-startup.md) finds only a 0–4.3ms local
startup advantage for a compiled Bun stub, which adds a roughly 60.5MiB
executable. The bundled Node client remains the M3 choice pending Linux evidence;
compiling the client would not resolve the daemon's memory failure.

Both final local 50-rerun stability sweeps pass after the PTY teardown fix:
7,100 repeated tests, zero failed runs. Earlier failures remain recorded
separately. Linux CI and its 50-rerun evidence, required checks, README
walkthrough, three-day use dates, publication, and provenance
still require verification before release approval. The source of truth is
Beads `prefaix-mbd`; the required gates are in [RELEASE.md](../RELEASE.md).
